Radio test subcommands
######################

.. contents::
   :local:
   :depth: 2

The available ``wifi_radio_test`` subcommands depend on the Wi-Fi chip series used by the build target.
Use the nRF70 Series table when building for an nRF70 companion IC (for example, nRF7002 on nRF54L15 DK).
Use the nRF71 Series table when building for an nRF71 Series SoC (for example, nRF7120 DK).
